Hoe we tellen

  • Scans via GitHub: GitHub bewijst met een ondertekend token dat de scan echt uit een repository komt. Ze tellen alleen mee als de eigenaar dat zelf aanzet met meetellen: "true"; in ons voorbeeldbestand staat het uit.
  • Zelfscans met een AI-agent: de agent vraagt eerst of je wilt meetellen. Ze tellen alleen mee met een geldig bewijsbestand van een echte dagversie en een sessiecode die maar één keer werkt. We vermelden ze apart, omdat we ze minder goed kunnen controleren.
  • We ontvangen alleen de letter. Geen code, geen bevindingen, geen naam van de repository. Per project bewaren we een onomkeerbare code, zodat we de eerste en de laatste score kunnen vergelijken.
  • Hoogstens {{ 10 }} scans per project per dag tellen mee. Pull requests tellen niet mee.
  • Op niveau 1 is B de hoogste score. Een A kan pas na een keuring.
