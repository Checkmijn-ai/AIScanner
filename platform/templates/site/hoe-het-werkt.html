Meten

De scanner van vandaag draait in je eigen omgeving, zonder netwerk. Na een paar minuten heb je je score en de lijst van bevindingen. Er gaat niets naar ons.

Typ na 2 à 3 minuten: verder

Zo lang duurt de scan in GitHub. Je bouwtool toont dan je score en de bevindingen, en vraagt of hij mag herstellen. Zeg ja, en typ na het herstel weer verder voor je nieuwe score.

Wat je krijgt

  • In je project: .checkmijn/RAPPORT.md met de score, het verloop van je scores en alle bevindingen.

Gratis bij scannen via GitHub

Lekkenwacht: een seintje bij een nieuw lek

Elke dag duikt er wel ergens een lek op in een veelgebruikt pakket. De lekkenwacht kijkt elke dag of het jouw project raakt.

  1. Elke nacht maken we een nieuwe scanner met de nieuwste lijst van bekende lekken.
  2. Elke ochtend scant GitHub je project daarmee opnieuw, in je eigen omgeving.
  3. Is er een nieuw kritiek of hoog lek in een van je componenten, dan opent de scan een issue in je repository, met wat er lek is en naar welke versie je moet bijwerken. GitHub stuurt je daarover een mail.
  4. Heb je het opgelost, dan sluit het issue bij de volgende scan vanzelf.

Wat je moet weten

  • Er gaat niets naar ons: de lijst van je componenten blijft in je eigen GitHub.
  • Staat alles in orde, dan gebeurt er niets: geen mail, geen extra commit.
  • In een openbare repository maken we geen issue (dan leest iedereen mee); daar mislukt de run, en ook dan mailt GitHub je.
  • De lekkenwacht ziet de pakketten in je project. Lekken in PHP zelf, je server of WordPress-plugins ziet hij niet; daarvoor komt de betaalde Lekkenwacht Plus, met een waarschuwing per mail.

Uitzetten: zet waarschuwen: "nee" in het workflowbestand.

Werkt het?

  1. Ga in GitHub naar Actions → checkmijn.ai en klik op Run workflow (of wacht tot morgenochtend).
  2. Open de run: onderaan de samenvatting staat een regel die begint met "Lekkenwacht", bijvoorbeeld "geen kritieke of hoge lekken in componenten".
  3. Wil je de mail zeker krijgen? Zet in GitHub bij Settings → Notifications e-mail aan, en kies bij je repository Watch.

In een openbare repository zet GitHub geplande scans uit na 60 dagen zonder activiteit. Een privé-repository heeft daar geen last van.

Vaak gevraagd

Kost het iets?

Niveau 1 is gratis, voor altijd. Je betaalt alleen als je een keurder wilt laten meekijken (niveau 2 en hoger).

Kan mijn code uitlekken?

Nee. De scanner draait bij jou, zonder netwerk. Er gaat alleen iets naar ons als jij een rapportlink aanzet, en dan versleuteld met een sleutel die alleen jij hebt.

Mijn score is slecht. Wat nu?

Dat komt vaak voor bij een eerste scan, zeker bij apps die snel met AI gebouwd zijn. Laat je agent eerst de kritieke bevindingen herstellen en scan opnieuw.

Is een B een keurmerk?

Nee. De scanscore is een uitslag van een meting op een moment. Wil je bewijs voor een klant, dan is een keuring vanaf niveau 2 de volgende stap.

Elke dag een nieuwe, ondertekende scanner

Elke nacht halen we de nieuwste lijst met bekende lekken op (GitHub Advisory Database), bouwen we een nieuwe dagversie van de scanner, berekenen we het controlegetal en ondertekenen we het manifest met Ed25519. Je vindt ze in latest.json en versies.json. Hoe je het zelf nakijkt, staat bij open source.
