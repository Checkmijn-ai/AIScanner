Met een AI-assistent

Voor Claude Code, Cursor, Copilot, Replit en andere assistenten die opdrachten kunnen uitvoeren.

  1. Open je project en plak de zin hiernaast in je assistent.
  2. Je assistent legt uit wat er gaat gebeuren en vraagt of het mag.
  3. Hij haalt de scanner van vandaag op en controleert of die echt van ons komt.
  4. Je krijgt je score en de bevindingen te zien.
  5. Zeg je "ja", dan lost hij ze op en scant hij opnieuw.

Typ na twee minuten verder

Je bouwtool toont je score en vraagt of hij mag oplossen. Zeg ja. Typ daarna weer verder voor je nieuwe score.

Nog niet klaar? Dan zegt je bouwtool dat. Probeer het een minuut later opnieuw.

Wat je krijgt

  • Een rapport in je project (.checkmijn/RAPPORT.md) met je score en alle bevindingen.
  • Een persoonlijke link naar hetzelfde rapport, mooi opgemaakt.
  • Een nieuwe scan bij elke wijziging, en elke dag de lekkenwacht.

Wat er met je gegevens gebeurt

  • Je code blijft in GitHub.
  • Het opgemaakte rapport bewaren we versleuteld. Alleen wie de link heeft, kan het lezen. Wij niet.
  • Is je repository openbaar, dan komt het rapport er niet in. Anders kan iedereen je lekken lezen.
  • Met meetellen: "true" telt alleen je letter mee in de openbare resultaten. Zet het op "false" als je dat niet wilt.

Wil je bouwtool het bestand niet maken? Doe het dan zelf in GitHub: Add file → Create new file, naam .github/workflows/checkmijn.yml, met de inhoud die hieronder bij de pipeline staat.

Lekkenwacht: een seintje bij een nieuw lek

Bijna elke dag wordt er ergens een lek gevonden in een pakket dat veel apps gebruiken. De lekkenwacht kijkt elke ochtend of jouw app daar last van heeft.

Is dat zo, dan krijg je een melding in GitHub (en een mail) met wat er lek is en naar welke versie je moet. Is het opgelost, dan verdwijnt de melding vanzelf. Is alles in orde, dan hoor je niets.

Je lijst met onderdelen blijft in je eigen GitHub. Uitzetten kan met waarschuwen: "nee" in het bestand.

Wat hij bekijkt

De pakketten in je project, ook de pakketten die andere pakketten meebrengen. Voor JavaScript en TypeScript, Python, PHP, Go, Java en Ruby. En de versie van PHP, Node.js, Python, Ruby of Go als die in je project staat.

Nog niet: Rust en .NET.

Binnenkort: Lekkenwacht Plus

Ook voor wat buiten je code zit: je server, je databank, WordPress en plugins, je firewall. Je geeft op wat je gebruikt, wij mailen je bij een lek. We bewaren alleen namen en versies, zonder je bedrijfsnaam of serveradres.

Vaak gevraagd

Kost het iets?

De scan is gratis, en dat blijft zo. Je betaalt alleen voor een keuring.

Kan mijn code uitlekken?

Nee. De scanner draait bij jou en gebruikt tijdens het scannen geen internet. Elke nacht bewijzen we dat opnieuw.

Mijn score is slecht. Wat nu?

Dat is normaal bij een eerste scan. Laat je AI eerst de kritieke problemen oplossen en scan opnieuw.

Is een C een keurmerk?

Nee. Het is de uitslag van een scan die je zelf deed. Wil je bewijs voor een klant, dan is een keuring de volgende stap.
